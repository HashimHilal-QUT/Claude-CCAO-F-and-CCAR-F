# Human-Readable Domain Study Guides

> **Exam:** Claude Certified Architect – Foundations (`ccaf`)

> **Note:** The Markdown files in this directory are intended for human review, self-study,
> and offline reading on GitHub. Each answer and explanation is collapsed behind a
> **Show answer** toggle, so you can attempt a question before revealing the rationale.
> They are generated from the machine-readable dataset in
> [`questions/ccaf/jsonl/`](../jsonl/), which the interactive skill and sampler consume.
> Edit the JSONL, then run `python3 scripts/render_markdown.py`.
>
